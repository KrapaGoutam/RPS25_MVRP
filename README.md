# RPS25_MVRP - Multi-Vehicle Routing Problem (MVRP)

![Quantum Computing](https://upload.wikimedia.org/wikipedia/commons/6/6f/Qiskit-Logo.png)

This project solves the **Multi-Vehicle Routing Problem (MVRP)** using **Quantum and Classical Computing** techniques. It utilizes **IBM Qiskit**, **D-Wave Ocean SDK**, and **Capacitated Vehicle Routing Problem (CVRP) solvers** to optimize route planning for multiple vehicles.

## 📌 Features
- 🚚 **Supports both Trucks & Delivery Drones**
- 🔬 **Hybrid Quantum-Classical Optimization**
- 📍 **Interactive Map Visualization (Folium)**
- 🏎️ **Classical K-Means & Quantum Solvers**
- 🏗 **Built using Flask, Dash & Qiskit**
- 📊 **Dynamic Web-based Dashboard**
- ⏳ **Real-time Optimization Execution**
